# 🌍 Bamako

Bamako est une plateforme pédagogique conçue pour apprendre les fondamentaux du développement web à travers des cours, des exemples pratiques et des exercices interactifs.

## 🎯 Objectif

Permettre aux débutants de découvrir et maîtriser :

- HTML : structure des pages web
- CSS : mise en forme et design
- JavaScript : interactions et dynamisme

## ✨ Fonctionnalités

- Cours progressifs
- Exemples de code commentés
- Exercices pratiques
- Interface simple et intuitive
- Ressources pour approfondir les connaissances

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- JavaScript

## 🚀 Installation

1. Cloner le dépôt :

```bash
git clone https://github.com/votre-utilisateur/bamako.git
```

2. Accéder au dossier :

```bash
cd bamako
```

3. Ouvrir le fichier `index.html` dans votre navigateur.
